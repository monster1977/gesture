# Жесты рук — контекст проекта

Версия: **1.3.0** (тег `v1.3.0`)

## Назначение
Управление звуком и медиа на Windows жестами руки перед веб-камерой: распознавание через MediaPipe HandLandmarker, действия через pycaw (звук) и keybd_event (клавиши плеера). Две версии: консольная (`gesture_app.py`) и оконная на PySide6 (`gesture_qt.py`).

## Запуск
- GUI: `python gesture_qt.py` (заголовок окна показывает версию)
- Консоль: `python gesture_app.py [--camera N] [--hands N] [--delay SEC] [--volume-step PCT] [--version]`
- Значения по умолчанию: камера 0, до 2 рук, задержка 0 с, шаг громкости 10%.

## Жесты и действия
| Жест | Действие |
|---|---|
| Кулак | Выключить звук (все устройства) |
| Открытая ладонь | Включить звук |
| Большой палец вверх / вниз | Громкость плюс/минус шаг |
| Указательный | Следующий трек (VK_MEDIA_NEXT_TRACK) |
| Победа (V) | Предыдущий трек (VK_MEDIA_PREV_TRACK) |
| Коза | Play/Pause (VK_MEDIA_PLAY_PAUSE) |

Медиа-клавиши (VK 0xB0/0xB1/0xB3, отправка с KEYEVENTF_EXTENDEDKEY) глобальные — плеер может быть в фоне. Mute/громкость — через pycaw на все устройства вывода. Сглаживание: deque 8 кадров, минимум 3 совпадения.

## Зона распознавания (GUI)
Меню «Зона»: «Выбрать зону мышью» (обвести прямоугольник по видео, правая кнопка — отмена), «Использовать зону» (вкл/выкл), «Сбросить зону». Руки вне зоны игнорируются, область вне зоны затемняется. Зона хранится в нормализованных координатах 0..1 в `gesture_qt_config.json` рядом со скриптом.

## Архитектура
- `gesture_app.py` — ядро: `GestureRecognizer` (MediaPipe VIDEO-режим, `draw_texts` через PIL/arial.ttf для кириллицы), `HandAnalyzer` (`fingers_state`, `classify`, `stable_gesture`), `ActionGate` (задержка срабатывания), `AudioController` (pycaw; mute/volume на ВСЕ активные устройства вывода; кэш 2 с), `KeyController` (`keybd_event`), `GESTURE_ACTIONS`, `parse_args`.
- `gesture_qt.py` — GUI: `VideoWorker(QThread)` — камера (CAP_DSHOW с fallback, 1280x720, зеркалит кадр), распознавание, ROI-фильтр и затемнение, сигнал `stateReady`; `VideoLabel` — отображение и выбор зоны мышью (`QRubberBand`, нормализованные координаты); `MainWindow` — меню (Настройки/Зона/Справка), `ActionGate` для mute/медиа/громкости, статусбар (FPS, звук, громкость, руки); `SettingsDialog` — параметры.

## История версий
- **1.0.0** — консольная версия: распознавание жестов, mute/unmute всех устройств, громкость, медиа-клавиши N/P.
- **1.1.0** — CLI-параметры: `--camera`, `--hands`, `--delay` (задержка срабатывания через `ActionGate`), `--volume-step`.
- **1.2.0** — оконная версия на PySide6: настройки, зона распознавания, конфиг-файл, статусбар.
- **1.2.1** — исправления зоны: в `mouseReleaseEvent` сброс `self._origin` происходил до расчёта координат (TypeError внутри Qt, выбор зоны мышью не работал); `roi_enabled` нормализуется при старте (включён только при заданной зоне); «Использовать зону» из «Параметров» применяется сразу; проект перенесён в `C:\i\gesture`; версия в заголовке окна и флаг `--version`.
- **1.3.0** — медиа-команды переведены с букв N/P на системные VK-клавиши: Указательный → `VK_MEDIA_NEXT_TRACK` (0xB0), Победа (V) → `VK_MEDIA_PREV_TRACK` (0xB1), новый жест «Коза» → `VK_MEDIA_PLAY_PAUSE` (0xB3); отправка с `KEYEVENTF_EXTENDEDKEY`, работают глобально без фокуса на плеере. Mute/громкость остались на pycaw (все устройства, точные состояния).

## Важные особенности (грабли)
- НЕ править исходники через PowerShell (`Get-Content`/`Set-Content`/`-replace`): перекодирует UTF-8 в cp1251, кириллица ломается. Только инструменты Edit/Write.
- Кириллицу на кадре рисовать только через PIL + `arial.ttf`; `cv2.putText` её не поддерживает. Кракозябры в выводе консоли — артефакт отображения, файл в порядке.
- pycaw 20260927: у объекта `AudioUtilities.GetSpeakers()` нет `.Activate` — готовый интерфейс в `.EndpointVolume`; перечисление устройств: `EnumAudioEndpoints(EDataFlow.eRender.value, DEVICE_STATE.ACTIVE.value)` + `GetCount()`/`Item(i)`.
- Модель `hand_landmarker.task` скачивается автоматически при отсутствии (URL в коде).
- Среда: Python 3.14, PySide6, mediapipe 0.10.35, opencv 5.0.0.93, numpy 2.5.1, Pillow, pycaw, comtypes.
